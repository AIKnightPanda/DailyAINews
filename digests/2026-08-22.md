### Meta AI 高级总监 Madhu Guru：把 eval 压成一个总分，是「平均数的暴政」

Madhu Guru 是 Meta 的 Sr Director, AI，此前在 Google 主导过 Gemini、Veo 和 Nano Banana。他的「如何做好 evals」系列写到第五篇，这一篇专攻一个几乎所有团队都在犯的错：把一整套精心设计的 eval 结果塌缩成一个数字，往往只是因为某位高管想要一个「便于决策的简化指标」。他说 Gemini 早期就是这么干的。

「这就是平均数的暴政。AI 系统的质量不存在单一维度。」（原文："This is the tyranny of the average. AI systems do not have a simple dimension of quality."）

他举的例子很具体 —— 一个新模型：简单摘要 85% → 89%，基础事实问答 80% → 85%，复杂财务分析 70% → 63%。总分是涨的，但模型在你最前沿的那个用例上退步了，而那恰恰是唯一要紧的一格。

那加权总分行不行？他说更糟：「你等于给一个主观判断套上了虚假的数学精度。」（原文："you have created false, mathematical procession around a judgment call."）

他给的三条替代做法：

- 按前一篇讲的「阶梯」，维护一份带优先级的 eval 清单
- 找那些愿意看细节、不追求抽象简洁的人来读结果
- 把所有关键 eval 结果吃透 —— 在哪里失败、在哪里出色 —— 然后自己判断新系统对用户到底是变好了还是变差了

### Anthropic 上线 Claude Security：Mythos 5 扫 GitHub 仓库，按 token 计费

claudeai on X 用一条 thread 公布了 Claude Security。把它指向一个 GitHub 仓库，Mythos 5 会跨文件追踪数据流、推理各组件如何交互来找漏洞，每条发现都带 CWE 分类、置信度与严重度评级，以及一份建议补丁。

几个对开发者有直接影响的点：

- 建议补丁直接在 Claude Code on the web 里打开，用你团队本来就在用的模型
- 扫描按你现有套餐下的标准 token 用量计费，不是单独一档产品
- 团队拿到 Mythos 的结果不需要拿到模型本身 —— 「模型跑在扫描背后，只返回发现结果。」（原文："the model runs behind the scan and returns findings only."）
- 配套还有一支 Defender Advantage Fund，为开源安全提供 3500 万美元 credits，Cyber Verification Program 也将在未来几周扩容

官方的框法是「让前沿能力触达更多防守方」的其中一步，同时在和合作伙伴谈把 Mythos 5 集成进他们的安全产品与服务。

### Anthropic 的 Thariq：ELI5 是内部用得最凶的一个 skill

Thariq（Claude Code 团队）分享了 Anthropic 内部最近高频使用的一个 skill：ELI5。prompt 本身就是它的全部设计 —— 「像给一个完全不懂这个话题的人解释，用一个 HTML artifact，大图，少字。」（原文："explain like I'm someone who knows nothing about this topic, using a HTML artifact with big pictures and few words"）

他自己的用法不是给小孩讲道理，而是拿来快速切进一个陌生问题：`/eli5 how does this module work`、`/eli5 why did we make this tradeoff`、`/eli5 what caused this incident`。第三个尤其实用 —— 事故复盘时最缺的就是一张让所有人对齐的图。

他说还在纠结要不要做成官方 plugin，但现在就可以装来试：

```
claude plugin marketplace add anthropics/claude-plugins-community
claude plugin install eli5@claude-community
```

### No Priors：Chess.com 教给我们的超人类能力课，对谈 CEO Erik Allebest

**核心结论：机器彻底碾压人类之后，人类对这件事的热情不但没死，反而涨了 —— 而且是因为 AI 变强才涨的。**

Erik Allebest 有资格讲这个，因为他手里握着这场实验的全部数据。他 2005 年在破产拍卖里花 5.6 万美元买下 chess.com 域名，当时投资人几乎一致劝阻；他偏偏走了完全相反的路线：不融资、全远程、只死磕用户体验。今天 Chess.com 有 2.5 亿注册用户、1000 万日活、5000 万月活、2 亿美元年收入，团队 650 人。

反直觉的部分在于 AI 的两段式影响。1997 年 Deep Blue 击败卡斯帕罗夫后，唱衰声一片；Stockfish 这类「完美引擎」确实让棋一度变得乏味 —— 棋手被迫模仿机器的机械下法。真正的转折是神经网络引擎 Leela Chess Zero：它下得凶、走法不合常规，反倒重新点燃了人的兴趣。

「有意思的地方在于，计算机起初让国际象棋变得无聊了一点，但后来却让它刺激了太多。」（原文："And so what was interesting is that like computers at first made chess a little bit more boring, but then made it so much more exciting."）

他给的解释是一条更普适的判断：「人类根本上想做的是人类的事 —— 人与人竞争，人去创造，人去解决问题。」（原文："Fundamentally, humans want to do human stuff. That's, you know, humans competing against other humans. It's humans making things. It's humans solving problems."）他把这个类比到音乐：当音乐无限供给时，人们反而回头去听 Beatles 和 Led Zeppelin，因为经典是大家能共享的那个东西。棋恰好占住了这个位置 —— 免费、规则永不改动、没有战利品盒、没有皮肤、零运气成分、极复杂却极易学。

两个具体的产品判断值得记：

- **学习没有捷径。** 他看过数百万棋手的学习数据，结论是只有重复，习惯的复利才是关键。AI 工具能让过程更顺，但消不掉必须付出的练习量。Chess.com 用 AI 做客服自动化、数据分析、内部知识管理和 AI 教练反馈，最新的尝试是聚合玩家统计后直接告诉你：想升一级，具体该练哪几项。
- **Gambit 扑克平台的核心创新是评分，不是筹码。** 这一步针对的是人的心理：输 100 美元他不在意，掉 100 分评分他难受。用评分体系把扑克从纯赌博挪向技能展示。

至于超人类智能，他相信它就要来了，但认为真正的问题不在技术而在文化 —— 财富和权力集中在太少人手里；技术本身中立，取决于握着它的人怎么用。而棋本身就是他最有力的论据：即使机器完全统治了这个领域，人还是想跟人比、想习得技能、想看见卓越。
