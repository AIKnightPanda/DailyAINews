### AI & I by Every：微软 CTO Kevin Scott 谈"为 agent 而生的互联网"

**核心结论**：现在真正卡住 AI 落地的不是模型能力不够，而是"能力过剩"（capability overhang）——模型已经比大多数产品实际用到的能力更强，行业需要补的是把这份能力真正交付给用户的最后一公里，而这最后一公里需要一个像互联网一样开放、大家都在说同一种协议的"agentic web"。

Kevin Scott 是微软 CTO，写下第一行代码到现在已经四十一年，业余时间做陶艺、做木工、做皮具。他谈到用 agent 写代码这件事时说，自己见过软件开发方式发生非同小可变化的时刻不止一次："如果你真的热爱自己做的事，你一定会对怎么做这件事有很强的看法——这不是过去四十年里第一次软件开发的本质发生非同小可的变化。"他自己至今仍然固执地用 vi 写代码，即便他很清楚这早已不是最优选择。

谈到 **MCP**（Model Context Protocol）时，他认为这个协议之所以能被广泛采纳，恰恰是因为它足够简单、足够连贯，社区完全有能力自己把安全模型这一课补上。微软内部正在推动所有系统都用这套标准协议向公司内部写的 agent 开放。但他也坦承安全模型还没有定论，尤其是 agent 需要有身份，才能建立"谁被允许看到哪些资源"的授权体系——这是他和 MCP 团队正在重点补的一课。

他给一年后回看今天的预测很干脆：**那些还在等"技术还没准备好"当借口按兵不动的人，会被远远甩在后面**，因为一切都会持续变得更便宜、更强。他也指出，现在最有意思的创业公司往往不是在做差异化的基础设施，而是对某个具体问题有着比任何人都更细致的理解，然后拿现成的基础设施去解决它。
