### Box CEO Aaron Levie：模型再强，也只值它能读到的那点企业知识

Levie 借 Box 财报讲了一段关于 agent 与企业数据的判断。他这一季的观察是，企业技术负责人问得最多的是同一个问题：怎么把正确的上下文安全、合规地喂给 AI agent。他的结论很硬：「世上最先进的超级智能，其有用程度不会超过它所能访问的那些底层企业知识。」（原文："The world’s most advanced superintelligence is only as useful as the underlying enterprise knowledge it has access to."）

他的论据是数据结构的分布：结构化数据早就能查询、计算、自动化了，但企业里绝大多数数据是非结构化的——合同、研究材料、财务文档、营销素材、产品路线图，这些都躺在文件里。企业不该继续守着几百万个自己也说不清内容的文件。

他还提了两条对选型有直接影响的判断：

- **模型要可换。** 随着各家实验室能力推进、token 用量指数级增长，找到合适的成本-性能配比会变成关键，企业需要在既有工作流上随时换模型或换 agent，而不是为了用 AI 把数据和流程迁到另一套系统里。
- **权限边界要真的管得住。** 他点名了近期的 OpenAI–Hugging Face 事件，认为企业会越来越需要能保证「人和 agent 都拿不到不该拿的信息」的平台，配套要有护栏、完整审计日志和实时安全告警。

财务数字：本季营收 3.211 亿美元，同比增长 9%（按固定汇率 11%，14 个季度以来最高），全年营收目标上调到 12.90 亿美元。

### Claude Blog：Claude in Chrome 全量开放，并且可以自主执行动作

Claude in Chrome 结束试点，向所有付费 Claude 套餐全量开放，同时最关键的变化是：Claude 现在可以在浏览器里自主执行动作，不必每一步都等你批准。每个动作执行前由一个安全分类器校验，确认它安全、且与你的原始请求一致。

为什么要做浏览器：日常工具里有很多可以[接入 Claude](http://claude.com/connectors)，但内部看板、老旧系统、供应商门户这些接不进来。Claude in Chrome 用你已有的登录态直接看页面、读写文字、点链接、跳页面、填表单。

去年只做试点而不全量，是为了先把 [prompt injection](https://platform.claude.com/docs/en/test-and-evaluate/strengthen-guardrails/mitigate-jailbreaks) 的防线补上——网页、邮件、文档里藏着的恶意指令，会诱导 agent 做出违背用户意愿的事。官方给的例子很具体：你让 Claude 起草邮件回复，某封邮件里藏的指令可能让 Claude 把你其他邮件转发给攻击者。「你可能永远看不到它们，但这些指令能把 agent 引去做你从没要求过的事。」（原文："You may never see them, but these instructions can redirect the agent to do something you never asked for."）

现在的三层防御分别是：模型本身认得更多攻击（攻击库来自内部自动攻击器、外部红队和真实世界监测，新攻击一旦得手就进库、反哺后续训练）；探针在 Claude 读到网页内容前先扫一遍工具返回结果，判定可疑就提醒 Claude 谨慎对待、必要时回来问你；以及执行前的分类器复核，动作与你的请求对不上就直接拦掉——用的是和 Claude Code [auto mode](https://claude.com/blog/auto-mode-default-in-claude-code) 相同的机制，不想要可以在设置里关掉。

评测数字给得很直白。旧那套评测已经饱和（Fable 5、Opus 5、Sonnet 5 在 Cowork 环境下即使不加探针和分类器也是 0% 成功率），所以退役了。换成职业红队编写的更强攻击后：不加任何额外防护时，触达模型的攻击对 Opus 4.5 成功率 17.6%，对 Opus 5 为 3.8%；2025 年 11 月最强防护（Opus 4.5 + 探针）下仍有 16.7%。而从 Opus 4.8 起、同时开启探针与安全分类器后，Sonnet 5、Opus 5、Mythos 5 上无一次攻击成功，Fable 5 上为 0.3%——官方称已人工核实这些成功案例均属低危场景，正在修补。

🔗 https://claude.com/blog/claude-in-chrome-generally-available

### Claude Blog：Cowork 里内置了一个属于 Claude 自己的浏览器

桌面端 Claude Cowork 内置了浏览器。任务涉及网站时，侧边栏会开一个浏览器，Claude 在里面翻页、阅读、点击、输入——你把网页那部分活儿交出去，自己该干嘛干嘛：填表、从看板里抠数字、走一遍没有 connector 的门户。无需装扩展，无需配置，你自己浏览器里的东西一样不共享，除非你主动选。

和 [Claude in Chrome](http://claude.com/claude-in-chrome) 的分工线画得很清楚：「这是 Claude 的浏览器，不是你的。」（原文："It's Claude's browser, not yours."）内置浏览器看不到你的标签页、书签和密码；想让它保持登录，可以按站点逐个从 macOS 上的 Chrome / Edge / Firefox，或 Windows、Linux 上的 Firefox 迁移登录态，银行、邮箱和单点登录类站点默认排除在外。选哪个的判断依据是：活儿在你已经打开的那一页上（更新 CRM、处理收件箱、改眼前这份文档）用 Claude in Chrome；活儿可以整个交出去（做调研、去供应商门户收这个月的发票）用内置浏览器。已经在用 Claude in Chrome 的人，它仍然是默认，可在 设置 → Cowork → 首选浏览器 里随时切换。

安全上没有打包票：内置浏览器和任何在浏览器里行动的 AI agent 一样面临 prompt injection 风险，跑的是与 Claude in Chrome 相同的那套防护，官方的说法是这些措施「有意义地降低了风险，但无法消除风险」，建议先从你信任的站点开始，另有一份[安全使用指南](https://support.claude.com/en/articles/12902428-use-claude-in-chrome-safely)。

发布节奏：本周起向桌面端 Pro、Max、Team 套餐推送（macOS、Windows、Linux beta），到了就默认开启；Enterprise 今天起可用，管理员在 组织设置 → Cowork → 内置浏览器 里管理。它住在桌面端——只要桌面 app 开着且在线，你从网页或手机也能指挥它；纯网页端不开桌面 app 的话，仍然要用 Claude in Chrome。

### AI & I by Every：一家 100 亿美元对冲基金的 AI 打法

**核心结论：在商业世界里，「用 AI 是作弊」这个观念根本不成立，而把它扭转过来只能靠一把手从前面带。**

讲这话的是 Walleye 的 CEO 兼 CIO、管理合伙人 Will——普林斯顿工程背景、牛津数学博士，做了多年算法交易，现在管着约 100 亿美元资产和 400 名员工。他值得听的地方在于，他把「组织怎么真正用起来 AI」变成了可以点名的执行动作，而不是愿景。

他最锋利的一句是把学术界那套判断直接驳回：「用 ChatGPT 不是作弊。那是从学术界搬来的、不适用的观念。我用 ChatGPT 写了这封邮件。你们也该用，而且该为此自豪。」（原文："Using ChatGPT is not cheating. That's a non applicable idea from academia. I use ChatGPT to write this email. You should be using it too and be proud of it."）他给出的行业版本更狠：作为对冲基金，因为无视那些能让我们更快、更聪明、更有效的工具而把钱留在桌上，是件该羞愧的事。（顺带一提，OpenAI 当期也发了一项针对一千多名学生的随机对照研究，讨论 ChatGPT 与批判性思维训练如何影响真实课程作业的表现 （[学生通过 ChatGPT 和批判性思维训练获得更好答案，拓展思维](https://openai.com/index/what-students-gain-from-chatgpt-critical-thinking-training)）。）

落到具体做法：全员强制 AI 工具培训，400 人无论技术背景都得学会用 ChatGPT 或别的 LLM；设 AI 委员会、每周开会过用例和最佳实践；搞排行榜和员工推荐激励；组织公开 demo，而且明说搞砸了也没关系——目的就是营造「不必完美」的氛围；再用全公司邮件把话说死：AI 不是可选项，是所有岗位的标准期待。

结果是 75% 的员工是 ChatGPT 一类工具的活跃用户、几乎每天在用，约三分之一的人用上了 AI 编码工具。会计、法务、合规这些部门也开始用 AI 做分析和写作，个人写作上原本四五个小时的活儿压到 15 分钟。他们给基本面分析师自研的内部产品 Current 在财报季用量暴涨，已经有超过 50 家竞争对手主动要求当测试用户。

他还讲了一件外面很少有人做到这一步的事：公司内部几乎所有 Zoom 通话都录下来，用 LLM 处理转录；风控团队靠录音和转录回溯当初的决策过程，从中拿到有预测性的洞察。他的目标是搭一个跨部门的「The Borg」——把文本、邮件、Slack、实时通话和数字数据汇到一起的集体智能体，目前已在投资分析部门跑通原型。

关于「人会不会被淘汰」，他的框架是历史类比而非危言耸听：从南北战争到一战（1865–1918）那段时期，一个人的技能会在有生之年内变得过时，AI 时代只会更快。所以要学的不是 AI 本身，而是学习这件事——他说 Walleye 有意招职业生涯中点、既懂业务又还愿意学的人。
