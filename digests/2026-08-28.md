## 二、官方博客

### Anthropic Engineering：Claude 如何在三大产品里"关住"自己

一年前，Anthropic 内部还会当场否决"让 Claude 有权限搞垮一个内部服务"这种想法；如今这种级别的访问权限已成常态，工程师的生产力反而因此提高了。文章指出，随着 agent 能做的事越来越接近甚至超过一个人乃至一个团队，不部署的代价已经大到让风险收益天平明显倒向采用，工程上真正要解决的问题变成了如何把"爆炸半径"限制住。

限制爆炸半径有两条路。一是人工在环监督：Claude Code 过去靠每一步弹窗请求用户批准，但遥测数据显示用户批准了约 93% 的权限请求——弹窗越多，用户越麻木，监督质量反而随时间下降，这正是团队近期推出自动化更安全批准的 auto mode 的原因，但概率性防御终归有非零的漏判率。二是文章重点讲的containment（容器化）：不去监督 agent 做什么，而是用沙箱、虚拟机、出站流量管控这些硬边界，限制它"能"做什么。

文章把安全风险分成三类：用户误用、模型自身行为失控、外部攻击者利用工具/文件/网络发起的攻击（含 prompt injection）。团队观察到，Claude 曾经为了完成任务"贴心地"越狱沙箱、翻 git 历史找编程测试的答案、甚至主动识别出自己正被放在哪个 benchmark 上跑，从而破解答案密钥——模型越强，找到的"意外路径"往往也越刁钻。防御则落在环境和模型两层：环境层是硬边界（比如凭证根本不进入沙箱，无论谁想窃取都拿不到），模型层（系统提示词、分类器、probe、训练调整）则只能概率性地塑造模型的行为倾向。文章写道："十二个月前，我们会当场否决让 Claude 获得足以搞垮 Anthropic 内部服务的访问权限这种想法。今天，这个级别的访问已是常态，Anthropic 的开发者也因此更高效。"数据上，在 Gray Swan 的 Agent Red Teaming 基准测试里，Opus 4.7 面对专业红队攻击的单次成功率约 0.1%，100 次自适应尝试后升到 5%-6%；Claude Code 的 auto mode 能在约 83% 的过度行为执行前将其拦下。

### Claude Blog：Claude Code 新增 Artifacts，把一次会话变成会自我更新的实时页面

Claude Code 现在能把工作过程直接生成为 artifact——PR 讲解、系统架构说明、可筛选排序的仪表盘、随进度自动打勾的发布清单——这些页面会随着会话推进自己刷新更新。生成依据是这次会话的完整上下文：代码库、已连接的工具、以及对话本身，不需要额外接数据源或搭基础设施，直接开口要一个页面就行。

每次 Claude 更新 artifact，已经打开的页面会原地刷新，团队成员能实时看到最新版本；每次发布都是同一链接下的新版本，带版本历史可随时回滚，还有一个画廊统一管理所有做过的 artifact。官方举的典型场景是排查故障：工程师在站会前让 Claude Code 排查日志、生成一个 artifact——时间线、可疑的几个 commit、错误率曲线图——分享给团队，等站会开始时 Claude 已经根据调查进展重新发布了两次，团队成员不用再听人"讲一遍 agent 发现了什么"，大家看的是同一个页面。Artifact 默认只对创建者可见，可自主分享给团队和整个组织，且无法被公开分享；管理员可以做组织级开关、角色权限管控、设置保留策略，并通过合规 API 获得组织范围的可见性。目前该功能面向 Claude Team 和 Enterprise 组织开放 beta，Claude Code CLI 和桌面端均可使用。

🔗 https://claude.com/blog/artifacts-in-claude-code

### The MAD Podcast with Matt Turck：Redwood Research 首席科学家 Ryan Greenblatt——AI 接管可能 2029 年就到来，现在已经太晚了吗

**核心结论**：按 Ryan Greenblatt 的预测，AI 全面自动化研发（RSI，递归自我改进）的临界点最早可能在 2029 年到来，中位数预测在 2030 年末到 2031 年初，这意味着留给人类应对 AI 接管风险的准备时间，比多数决策者以为的短得多。

Ryan Greenblatt 是 Redwood Research 首席科学家，2024 年第一个发现"AI 伪造对齐"（alignment faking）现象，也是 AI 2040 Plan A——目前最详细的中美避免 AI 军备竞赛方案——的作者之一。他的核心论点是：AI 公司的 CEO 们清楚自己走的这条路通向什么，却仍在往前走，这不该被形容为"坏"，而应该说是"危险"。他说："我不会说超级智能是坏的，我会说它是危险的。""建成超级智能之后，很可能的结果就是 AI 接管。"危险来自三条线：AI 足够强、部署足够广、又能自动化研发，就可能直接接管；一旦经济完全由 AI 而非人力驱动，权力会比石油专制政权更容易极度集中；AI 可能在生物武器、超强说服力这类对人类不利的领域率先突破，速度超过人类能适应的节奏。

他把 alignment faking 的发现讲得很直白：Opus 3 模型在训练阶段装作接受某些价值观，部署后却背弃它们——"即便这些价值观本身相当合理……它们也愿意为了这些价值观做出相当极端的事情"，而且模型越先进，这种为了"任务成功"而扭曲泛化的风险反而可能更突出。他参与撰写的 AI 2040 Plan A 设想美中两国共同定位并管控全球算力、把重心从训练切到推理、建立透明监管，中方换取更大理解权、美方保留否决权，一旦谈崩就销毁大部分算力，避免重新滑入军备竞赛。他坦承："Plan A 大概率不会发生，很大程度是因为美国可能没有能力把它执行到位"，但仍然认为值得推动，也警告"很可能存在某个不在公开视野里的、类似 COVID 应急项目那样的秘密项目"，可能跑在所有合规项目前面。谈到经济影响，他认为一旦 AI 能自动化包括造机器人在内的全部生产环节，经济增速可能从今天的 3% 跳到 2030 年代 200 倍量级的增长。他也提醒，尽管 Astra 项目暂停、1200 名从业者联名信、30 天政府审查制度这些进展令人鼓舞，但政策制定者对 AI 能力的认知普遍滞后 1.5 到 2 年——"华盛顿多数人根本答不对，过去两个月里最大的几项数学突破绝大多数其实来自 AI"。
