### Thibault Sottiaux：Astra 需求「前所未见」，可能被迫暂停新 Pro 订阅

OpenAI Codex 与 ChatGPT 负责人 Thibault Sottiaux 说，GPT-6 Astra 上线后的需求量是他此前从没见过的，即便 OpenAI 经历过陡峭增长期也没遇到过这种量级。团队正在想尽办法维持供给，但优先级是先保住现有用户的体验——如果需求持续这么猛，可能不得不暂停新的 Pro 订阅。

「Astra 的需求真的是前所未见。我们在想尽一切办法维持这个需求，但如果情况持续下去，我们可能不得不暂停新的 Pro 订阅一段时间」（原文："Demand for Astra is really unprecedented. We're pulling all the levers possible to sustain the demand... we might have to pause new Pro subscriptions for a bit if this continues."）

同一天，他还回应了 Anthropic 旗下 Claude Code 上线的后台 computer use 功能，称赞对方「追上了 Codex 五月的水平」，并表示 OpenAI 大约四个月前就已经在实践中解决了 computer use，愿意继续靠抢先发布倒逼同行加速迭代。

「先把好功能发出来，是逼其他实验室也跟着发布的好办法。在别的实验室更认真对待发布这件事之前，我们会一直这么干，这对所有人都好」（原文："Shipping great features first turns out to be a great way to encourage other labs to ship too. We will continue to do this until other labs pay more attention to shipping."）

🔗 https://x.com/thsottiaux/status/2097559315150426222 · https://x.com/thsottiaux/status/2097482341916852719

### Boris Cherny：prompt injection 在实践中已经解决，但不是靠模型本身

Anthropic Claude Code 团队的 Boris Cherny 说，单靠「对齐得好的模型」还不足以独立解决 prompt injection，但把最新模型和额外的防护层叠加起来——默认对所有流量开启的 prompt injection 探针，加上默认开启的 auto 模式——已经在实践中把这个问题解决了。

「对齐得好的模型本身还不足以解决 prompt injection。不过，把我们最新的模型和 prompt injection 探针（默认对所有流量开启）以及 auto 模式（也是默认开启）叠加起来后，我们已经在实践中解决了这个问题。一点点脚手架式的防护就有用」（原文："well aligned models are not sufficient to solve prompt injection by themselves yet. That said, we have solved prompt injection in practice when layering our latest models with prompt injection probes... and auto mode... The little bit of scaffolding helps."）

发完这条后他又补了一句，说自己没想把话说得那么阴阳怪气，这段进展是真实的、也确实值得高兴，希望大家继续保持。

🔗 https://x.com/bcherny/status/2097557079762624563 · https://x.com/bcherny/status/2097368503624085773

### Aaron Levie：个人助理类 agent 会是下一个大品类，而这正好是 Meta 的主场

Box CEO Aaron Levie 说，个人助理 agent 会是一个很让人兴奋的 AI 品类——这是第一次出现「高 token 用量的 agentic 场景对普通消费者也说得通」的情况。他认为这个方向天然利好 Meta：算力密集、能靠广告和电商变现、软件体验又适合大规模分发。

「个人助理 agent 会是一个非常令人兴奋的 AI 品类。这是第一次，高 token 用量的 agentic 场景对消费者来说也讲得通了……这恰好正中 Meta 的长处：需要大量算力、能靠广告和电商变现、以软件体验为主所以能规模化分发」（原文："Personal assistant agents are going to be a very exciting AI category... this certainly plays directly to Meta's strengths: lots of compute required, can monetize with ads and commerce, software focused experiences so can distribute it at scale"）

### Peter Yang：别拿「治愈癌症」这种话去消费病人和家属

AI 教程博主 Peter Yang 转发一条声称「个性化疫苗能治愈癌症」的推文，提醒大家这类说法很有误导性：黑色素瘤上的初步进展不代表个性化疫苗对所有癌症都有效，一项试验里出现的希望也不代表大多数病人能用上或能受益。他直接向两位肿瘤科医生喊话，问个性化癌症疫苗离普及还有多远、卡在哪。

「这类推文既有意思又容易误导人。一方面，谁不希望有一种个性化疫苗能治好自己的癌症、减少化疗？另一方面，有很多病人和家属正在拼命找治疗方法……把这当成 2026 年癌症治疗的样子来呈现，并不属实」（原文："On the one hand, who doesn't want a personalized vaccine that treats their cancer and reduces the need for chemo?... Presenting this as what cancer treatment looks like in 2026 is just not true"）

### Aditya Agarwal：对 AI 的加速心态很矛盾——乐观又焦虑

SPC 普通合伙人、Bevel Health 联合创始人 Aditya Agarwal 说，自己一贯是那种"往最乐观处看"的人，也确实相信今天是他人生中"最不好、但不是最差"的一天，明天会更好。他对 AI 的走向整体乐观，但也真实地对变化速度、以及人类还看不懂这些系统到底怎么运作这件事感到焦虑。

「这是个奇怪的时期……我对 AI 的走向非常乐观。但我也真的对变化的速度、以及我们没能力理解这些（极其）复杂的机器到底是怎么运作的，感到焦虑。我一贯的态度是「让我们放手去做」，唯一的出路就是往前走，让我们继续建造」（原文："I am super optimistic about where AI is going. But I also find myself genuinely anxious about the pace of change and our inability to understand how these (insanely) complicated machines work... The only way out is through. Let us build."）
