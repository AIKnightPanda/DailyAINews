### Box CEO Aaron Levie：跑了一圈企业客户，网络安全焦虑和「模型混战」是眼下最大主题

Box CEO Aaron Levie 这周见了几十位银行、媒体、信息服务、保险和咨询行业的技术负责人，专门聊企业里的 agent 落地情况，总结出几个眼下最热的话题。第一是网络安全：所有人都在为 AI 带来的漏洞增长速度紧张，尤其是 OpenAI-Hugging Face 事件之后，硅谷之外的企业没有那么「存在主义」，但操作层面的担忧很实际，新发现的漏洞多到跟不上。第二是「模型混战」持续：大多数企业内部同时部署多个前沿模型，标准化太难，不同团队和场景偏好不同，但钱仍然集中砸在少数几家；开源模型在企业里还很早期，很大程度是因为缺少「国产」的前沿开源选项。

第三是 agent 的安全和身份管理——企业想给每个 agent 建身份、控制它能做什么,但现实是 agent 有时必须完全代表用户本人行动，这两者天然冲突。第四是流程再造：真正的 ROI 出现在企业敢于按 agent 的方式重新设计工作流本身，而不是把 agent 简单叠加在旧流程上；驱动这类变革最好的经验，来自把 FDE（前线部署工程师）直接嵌进业务部门。第五是架构「毫不留情」地反复更换：很多企业过去一两年内换了不止一次供应商，「试了 X 不行换 Y」成了常态，因为创新太快，没人会等一个供应商慢慢把事情做对。第六是评估（evals）：大多数企业对自己工作流的评估仍处于很早期阶段，谁能先把这件事做好，机会很大。最后，遗留系统仍是拖后腿的老问题——数据散落在没为 agent 时代设计的老平台里，企业得先花大量时间清理这些老系统。

「多数公司发现，agent 真正的上限在于能不能改变工作流程本身，从而拿到 AI 的全部收益。当企业能调整工作流去配合 agent 改变工作方式，而不是只是把 agent 叠加在现有流程上时，投资回报率要高得多」（原文："Most companies realizing that the big upside of agents is when they can change the actual workflow itself to get the full gains from AI. Far more ROI when companies can adjust their workflows to support agents changing how the work happens instead of just layering on agents into the existing flow."）

同一天，Levie 还宣布 Box 和 OpenAI 加深合作，让企业能在 ChatGPT 里安全地调用 Box 里的企业内容——他称之为"软件正在变得无头（headless）"，未来的工作方式会是 AI agent 随处处理数据、执行工作流。

### Anthropic 的 Boris Cherny：Claude 写的生产代码，该按什么标准把关

Anthropic Claude Code 团队的 Boris Cherny 回应了一个常见问题：Claude 写的代码到底该按多严的标准审。他的答案是原型代码和生产代码要分开看——扔了就扔的原型、影响面很小的东西，写得不完美没关系；但生产代码的标准应该比人写的更高。Anthropic 内部靠一整套护栏做到这点：大量 lint 规则、大量测试、Claude 驱动的端到端测试、每天跑的 Claude 模糊测试（fuzzer）、自动代码审查和安全审查、自动代码重构等等。没有这些，代码库很容易堆成一堆将来没法维护的烂账。

他给读者的建议是：如果 Claude 写的代码没达到你的质量门槛，先试试换成最新的前沿模型（Opus 5 或 Fable 5.1）、把 effort 调到 high 或 xhigh、把公司的工作方式写进 CLAUDE.md 和 skills 里教给 Claude；实在不行就更主动地引导 Claude，或者让它去修复积累的技术债、重写代码库让后续更好维护，或者等下一代模型。

「你的工作是守住代码质量这条线。如果 Claude 写的代码没达到标准，可以试试：换成最新的前沿模型（Opus 5 或 Fable 5.1）；把 effort 调到 high 或 xhigh；投入时间完善你的 CLAUDE.md 和 skills，把怎么在你的代码库里工作简明地教给 Claude」（原文："Your job is to hold the bar on code quality. If Claude's code doesn't meet the bar, try: Using the latest frontier model (Opus 5 or Fable 5.1); Increase effort to high or xhigh; Invest in your CLAUDE.md and skills to succinctly teach Claude how to work in your codebase."）

### OpenAI 的 Thibault Sottiaux：Astra 需求太猛，暂停 200 美元 Pro 版新订阅

负责 Codex 和 ChatGPT 的 OpenAI 高管 Thibault Sottiaux 宣布，为了让现有用户继续获得稳定体验和 Astra 的持续访问，OpenAI 将暂停 200 美元/月 Pro 版的新订阅——这一档给系统带来的压力最大，暂停新订阅是他们能想到的、在维持尽可能广的访问范围的同时，冲击最小的做法。他强调现有账户不受影响，团队正在尽快扩充算力容量；其他所有价位的订阅和 API 都照常开放。

「为了确保现有用户获得出色体验并持续访问 Astra，我们将暂停 200 美元 Pro 版的新订阅。这一档给我们系统带来的压力最大，我们想采取影响最小的一步，同时尽可能保持最广泛的访问。现有账户不受任何影响，我们正在尽快扩充更多容量」（原文："To make sure our current users have an incredible experience and continued access to Astra, we are going to pause subscriptions to our $200 Pro plan. These put the most strain on our systems and we wanted to take the smallest step that allows us to continue giving the broadest access possible. There is no impact to existing accounts and we are working on adding more capacity as fast as we can."）

同一天他还提到，「按需伸缩 agent」的能力已经通过 API 开放——这正是 ChatGPT Work 背后跑的基础设施，一分钟内就能上手。

### The MAD Podcast with Matt Turck：When AI Improves Itself | Richard Socher (Recursive)

**核心结论**：科学进步放缓不是因为知识不够，而是知识体系碎片化成了没人能跨越的迷宫；AI 能像"通用语言"一样把碎片化的学科重新缝合起来，前提是算力和数据都要跟上。

讲者 Richard Socher 是斯坦福引用量最高的 AI 研究者之一，曾任 Salesforce 首席科学家，最近为新公司 Recursive 融资 6.5 亿美元，专注"递归自我改进"（Recursive Self Improvement），新书《The Eureka Machine》9 月 22 日出版。他的核心判断是：科学进步看起来在放缓，不是因为投入不够，而是知识体系从文艺复兴时期的"集中"变成了今天的"分散迷宫"——34,000 本期刊，每个学科分裂成数千个子领域，掌握一个领域要耗上数年，跨学科的综合创新反而变难了；学术文化也不鼓励冒险，太新颖的想法容易被拒稿。

「文艺复兴时期的博学者知识量不算大，正因为如此，他们才能提出跨学科的洞见——而这在今天已经不可能了」（原文："The Renaissance man had only a small body of knowledge, and therefore were able to come up with cross-disciplinary insights, but this is no longer possible."）

Socher 认为 AI 对生物学的作用，会像微积分对物理学的作用——让人能处理复杂系统里层层叠叠的关联。他反直觉的论点是：看似简单的"预测下一个词"这个训练任务，本身就是 AI 习得世界知识的方式——模型看多了"我在纽约，向北开"这类句子，自然会学到纽约北边多半是波士顿这样的大城市；这个过程重复数万亿次后，AI 在蛋白质折叠、分子结构、药物设计等领域都攒下了隐含知识。AlphaFold 只用语言序列训练却学到了蛋白质三维结构、Profluent 用类似方法设计出比 CRISPR-Cas9 更精准的基因编辑工具，都是证据。

「next token prediction 是一个如此优雅却简单的想法，几乎能融入任何领域的知识」（原文："next token prediction is such a beautiful yet simple idea that incorporates knowledge about almost any domain."）

他把要建的"Eureka Machine"归纳成四根支柱：大语言模型摄入的世界知识、超越人类感知的科学测量数据（引力波、伽马射线等）、从棋类游戏到虚拟细胞的模拟、机器人自动化实验；再往上叠加 AI agent 集群和科学家社群，靠开放式探索驱动创新。他判断可模拟、可验证的领域 AI 都能啃下来：从棋类到数学证明、编程，再到蛋白质设计、新材料、核聚变反应器；但生物学目前数据不足，还需要更多"敲掉某个基因看结果"式的扰动实验来训练虚拟细胞。

「凡是能被模拟的东西，AI 都会解决」（原文："Anything you can simulate, AI will solve."）

在药物发现上，他观察到传统流程要 8-10 年才能把一款药推进到三期试验，失败率还很高；而现在的公司已经能在 6-18 个月内产出多个二期候选药物，成功率也更高，有公司甚至能给每位病人定制化疗鸡尾酒。但他也提醒：临床试验本身的时间省不掉（某些副作用要观察三年），所以 AI 加速的是前期探索环节，不会出现"硬起飞"。最大的瓶颈其实是算力——Recursive 融的 6.5 亿美元里，4.1 亿美元已经承诺给了 Amazon 的算力协议，而这可能还只是起步价。

在工作和分配问题上，他的判断是 AI 冲击取决于需求的价格弹性：插画师恨 AI，是因为费用从 200 美元跌到 0.02 美元，但需求没跟着涨 1000 倍；编程恰恰相反——代码变便宜后需求反而更旺（Jevons 悖论），程序员反而更稀缺、更值钱。展望未来十年，他预期会看到罕见病治疗、个性化器官设计、能分解微塑料污染的合成细胞，但前提是算力和数据（尤其是生物学的扰动实验数据）都要大幅跟上。

「我们离智能空间的真正上限还差得远得远。而 AI 能走的路还远比这更长」（原文："Boy, are we far away from the true upper bounds of any of the spaces of intelligence. And there is still so much further that AI can go."）
