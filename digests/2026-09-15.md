### Box CEO Aaron Levie：agent 会把工作量吃掉 100 倍，企业数据保护是 21 世纪最复杂的治理难题之一

Levie 连发两条长文，先谈规模。他判断随着 agent swarm、更强的 computer use、新一波 API 和 MCP 上线，以及 Muse、Instinct 这类新形态产品出现，大家对「即将到来的 agentic workload」的认知都得更新——agent 未来会被扔去做的任务，远比现在想象的多得多，agent 在后台替我们查找信息、完成工作的量级，会是过去在单次会话里提示模型的 100 倍。他列举了具体场景：agent 会 24 小时不间断地帮你物色人才、盯着客户业务里的每个信号判断何时该推销、逐条处理会议记录提炼产品洞察、审查每一行代码找安全漏洞和 bug、对系统做暴力测试找问题。他的判断是，人类现在大概只摸到了这些 agent 最终会长成什么样子的 1%。

「我们会把 agent 扔去做远比最初想象多得多的任务，无论是工作还是生活里。agent 未来在后台替我们查找信息、完成工作的量级，会是过去我们能在单次会话里想象提示模型的 100 倍。」（原文："We're going to throw agents at vastly more tasks in our professional and personal lives than we had initially imagined. The kind of information that agents will go out and find for us and do work for us in the background is going to be 100X more volume than what we can imagine previously prompting in a single session."）

第二条转向安全。他的核心论点是：AI 世界里安全和生产力其实是一对绑在一起的东西——给 agent 太多不受限的信息访问权限，数据就很难真正管控；但要是把权限锁死，AI 又完全发挥不出生产力。他以 Box 自己举例：Box Shield 最近更新加入了基于文档分类等级、对 agent 能碰哪些内容做精细化管控的功能，团队也在做能自动侦测并告警（或拦截）agent 异常访问数据行为的功能。他认为这只是开始，OpenAI、Anthropic 这些实验室，Palo Alto Networks、Cisco、CrowdStrike、Okta 这些安全厂商，以及 Enclave、Method、Alterion、Runlayer 等一批初创公司，都会在这个方向上持续发力。

「安全和生产力在 AI 世界里是密不可分的。如果你给 agent 太多不受限的信息访问权限，你就很难真正管控和保护数据；反过来，如果你把一切都锁死，你也不会从 AI 那里获得任何真正的生产力提升。」（原文："Security and productivity gains are inexorably linked in the world of AI. If you give an agent too much unfettered information access, it will be difficult to truly control and protect your data; and conversely, if you lock everything down completely, you won't get any real productivity gains from AI."）

### Vercel CEO Guillermo Rauch：verifier 和 skill 是新的「框架」，请来 Google Cloud Run 创始人 Steren 主管 agent 计算原语

Rauch 借自家新出的 shadcn/lint 工具抛出一个论点：agent 的表现好坏，取决于你给它配的验证工具——校对器、编译器、类型系统、linter。他把这个总结成一句话：verifier 和 skill 正在成为新一代的「框架」。同一天他还宣布了一项人事任命：Google Cloud Run 的创始人 Steren 加入 Vercel，将主导 Fluid 系列计算产品（Functions、Containers、Sandbox、Builds）。Rauch 的判断是，serverless 是云计算的上一章，而 agent 是下一个前沿，需要专门为它设计的全新计算原语。

「agent 的好坏取决于你给它配的校对器、编译器、类型系统和 linter。shadcn/lint 能帮 agent 守住你设计系统的规则。往深了说：verifier 加 skill 就是新一代的'框架'！」（原文："Agents are only as good as the proof-checkers, compilers, type systems, and linters you give them. 𝚜𝚑𝚊𝚍𝚌𝚗/𝚕𝚒𝚗𝚝 helps agents stay on track with the rules of your design system. Meta: verifiers + skills are the new 'frameworks'!"）
