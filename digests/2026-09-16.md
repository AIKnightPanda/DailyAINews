### Box CEO Aaron Levie：应用层AI是万亿级机会，鸿沟本身就是入场券

Levie 抛出了一个直白的判断：AI 模型的能力和企业真正想自动化的工作流之间，隔着一道巨大的鸿沟，而这道鸿沟正是应用层的机会所在。要填上它，得把模型接到具体工作流上、经常还得重新设计流程、聚合对的上下文和数据、留出恰当的人工介入环节、推动变革管理、做领域专属的评测，还要管好数据和流程的安全与合规——事情很多，而且不会因为模型变强就消失。相反，模型能力越强，能碰的任务越复杂，这层没做好的代价反而更大。

「AI 模型的能力和企业真正想自动化的工作流之间，隔着一道巨大的鸿沟。」（原文："There's a massive chasm between the power of AI models and the ultimate workflows that enterprises are trying to automate."）

### Replit CEO Amjad Masad：新发的「决策模型」值不值得单独训练，他表示怀疑

针对本期 AINews 里刷屏的 TypeSafe「决策模型」Jev（[新的模型类别](https://x.com/CompleteSkeptic/status/2099925682726002904)、[重要警示](https://x.com/scaling01/status/2099960451358457971)——号称专为决策而非文本生成训练，速度快 20–200 倍、成本低 40–400 倍），Amjad Masad 引用发问：如果输出的范围本来就是已知的有限集合，为什么不直接训练一个模型去对着这些枚举值输出 logprobs，何必包装成一个新模型品类。

另外他还调侃了一把「AI 命名诅咒」——顶着「AI Safety」名头的公司反而把 AI 搞得不安全，「Effective Altruists」（有效利他主义者）既没效果又在助长犯罪，叫「Irregular」的安全公司则「经常」（regularly）翻车。

「AI 命名诅咒又发作了。『AI Safety』公司把 AI 搞得不安全，『Effective Altruists』既无效又在助纣为虐，『Irregular』则经常不靠谱。」（原文："The AI naming curse strikes again. 'AI Safety' firm made AI unsafe. 'Effective Altruists' are both ineffective and enabling criminal activity. 'Irregular' is regularly incompetent."）

### Every CEO Dan Shipper：测试了一周只吐概率、不吐文字的新模型，当裁判快 25 倍、便宜 600 倍

Shipper 说他们团队很少测新的基础模型，但这次测了将近一周——这个模型不产生文字输出，只产生概率分布，所以特别适合拿来做「判官」（judge）：原本要用顶级模型才能做的裁决任务，用它测下来快了 25 倍、成本低了 600 倍。结合本期 AINews 里 TypeSafe Jev 的发布背景（[新的模型类别](https://x.com/CompleteSkeptic/status/2099925682726002904)、[重要警示](https://x.com/scaling01/status/2099960451358457971)），这类专攻决策而非生成的模型正在成为建造者圈这两天的热议话题。

「我们几乎从不测新的基础模型，但这个我们已经在 Every 内部测了大概一周，效果很惊人。」（原文："we almost never test new foundation models but we've been testing this for ~a week @every and it's pretty wild."）

### Anthropic Claude Code 团队 Thariq：MCP 正在取代 CLI，成为集成的默认选择

Thariq（trq212 on X，Anthropic Claude Code 团队）说他没料到事情会这样发展，但现在他认为对大多数集成场景来说，MCP 比 CLI 更合适。原因是模型的工具调用能力已经好到可以把工具执行延后处理，而 MCP 现在也做到了无状态。他补充说，如果需要对数据做组合或过滤，直接在 MCP 工具里加 query 之类的参数就行。

「模型的工具调用能力已经好了很多，我们可以把工具延后执行，而且 MCP 现在是无状态的。」（原文："The models have gotten much better at tool calling, we can defer tools & MCP is now stateless."）

### Training Data：Box CEO Aaron Levie 谈重塑自我与企业 AI 扩散

**核心结论**：模型能力和企业工作流之间的鸿沟，才是应用层公司真正的机会所在——而且模型越强，这道鸿沟的价值反而越大。

Aaron Levie 是 Box 的创始人兼 CEO，Box 从云存储时代起步，现在做到年收入 13 亿美元的企业内容管理与协作平台，这两年他把公司整体方向转向了 AI 驱动的企业智能化，算是亲身在打这场应用层的仗。

他解释了一个反直觉的现象：为什么编码类 agent 这一年扩散得极快，但律师、销售这些其他知识工作的 AI 化却慢得多。核心原因不是模型不够强，而是编码的产出可以完全由生成的代码文本本身来衡量，而销售代表、律师的工作要受客户回复、时间表、预算这些外部因素严格约束；再加上程序员只要授权一个 GitHub 账号就能让 agent 工作，其他岗位没有这么现成的入口。更麻烦的是企业内部的权限体系——比如律师根本不能看到竞争项目的文件，这种硬边界目前最先进的个性化模型也处理不好。

Box 自己的做法是搭了一套叫「harness」的领域专属 agent 框架：基于对 Box 内部数百亿文件、用户搜索和文件选择习惯的理解，让 agent 可以反复搜索、重排序、抽取文本、生成向量，来回答关于海量数据集的问题。据他说，这套针对 Box 场景调优过的 agent，在精度和延迟上都明显优于直接调用 OpenAI 或 Anthropic 的原始 API。评测体系分两块：一块是生命科学、金融、公共部门等领域的「复杂工作 eval」，另一块是拿 Box 员工真实数据做的留存评测；模型排名大体上和编码基准的排名接近，目前 Fable 5.1 表现最好，Gemini 在某些具体用途上意外突出。

对未来，他判断开源模型的企业采用率目前低于预期，但成本驱动的长尾负载会逐步转向开源；5 年内，企业消耗的 token 里大约 90% 会是后台 agent 悄无声息用掉的，用户只看到结果，Salesforce、Box 这类系统记录未来会进化成给企业 agent 提供一流集成的 MCP server——为此他甚至愿意付出十倍的价格。

「应用层这里摆着的字面意义上是万亿到万万亿级别的机会，懂得怎么组建团队、真正打进企业的公司才会是赢家。」（原文："There is quite literally trillion to trillions up for grab at the applied layer, and the companies that that know how to build the teams and get to the enterprise will be the ones that win."）
