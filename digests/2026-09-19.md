### Thariq：Claude Code 开始支持 AGENTS.md，没有 CLAUDE.md 时会自动读取它

Thariq（trq212 on X），Anthropic Claude Code 团队成员，宣布 Claude Code 加入对 AGENTS.md 的支持：「今天开始，从 2.1.277 版本起，如果文件夹里没有 CLAUDE.md，Claude 会检查并使用 AGENTS.md。你可以在 /config 里切换这个行为。」（原文："Starting today in version 2.1.277, if there is no CLAUDE.md in a folder, Claude will check for and use AGENTS.md. You can toggle this behavior in /config."）

这个能力是靠 Claude Code 即将推出的 mods 机制实现的——「这是一个内置 mod，但你以后也可以自己动手做自定义版本的项目指令」（原文："This is a built-in mod, but you'll be able to build custom versions of project instructions yourself as you'd like too."），意味着 AGENTS.md 支持只是 mods 这套自定义框架落地的第一个例子。

### Aaron Levie：Box 用 Jev 做毫秒级决策，判断工单该不该升级

Box CEO Aaron Levie 演示了 Jev（by Typeface）在企业场景里的用法：从 Box 里拉出一份事故报告，判断它是不是面向客户、严重程度多高，据此把文件挪进升级、监控或复核三个文件夹之一，再顺手写入一条元数据模板实例——整个过程「近乎瞬时，成本几乎为零」。他说：「Jev 对 agent 在工作流里做出瞬间决策、数据分类、判断调用，以及企业里几百种其他场景会非常有帮助。」（原文："Jev will be super helpful for agents to make split second decisions in workflows, data classification, judgment calls, and hundreds of other use-cases in the enterprise."）

他列的潜在场景包括保险理赔、合同管理、贷款审批、安全复核、客户日志分析，判断这是「一类全新的 AI 用例」。

### No Priors：为什么扩散模型会赢下 AI 推理这场仗——对话 Inception 联合创始人兼 CEO Stefano Ermon

**核心结论**：扩散模型会成为 AI 推理的下一个主流范式——把推理阶段天然的并行处理特性和 GPU 架构对齐后，在困惑度（perplexity）持平的前提下，能比自回归模型快 10 倍。

Stefano Ermon 是 Stanford 教授、Inception 联合创始人兼 CEO，也是扩散模型的早期奠基人之一。他从 2014 年起在 Stanford 做生成模型研究，那时这个方向还很冷门，论文都不好发。2019 年，他和 PhD 学生 Yang Song 一起做出了扩散模型的核心思路——训练神经网络做图像去噪，此后扩散模型逐渐成为图像、视频、音乐等连续域生成的主流方法。2024 年，Inception 发表论文，首次证明扩散模型在离散的文本/代码域也能做到和自回归模型持平的困惑度，同时推理快 10 倍；他随后创立同名公司，两年内从研究原型走到了约 50 人规模、已有真实客户使用的 Mercury 模型。

他反复强调的一点是，软件层面的算法优化和硬件层面的优化不是二选一，而是相乘的关系：「你从软件那边拿到的收益，跟你从硬件那边拿到的收益是乘法关系」（原文："The gains that you get from the software, they are multiplicative with the gains you get from the hardware."）。这背后的原因是自回归模型在结构上必须串行——生成第十个 token 之前必须先生成完前面所有的，「这种负载没法很好地映射到 GPU 上」（原文："Autoregressive models are still sequential... that kind of workload does not map well to GPUs."），而扩散模型的并行特性天然贴合 GPU 的批处理能力。

他举了语音 agent 初创 OpenCall 的例子：原本要在 Cerebras 定制芯片上跑模型才能达到目标延迟，换成 Inception 的扩散模型后，用标准 NVIDIA GPU 就拿到了同样的推理速度，还顺带换来更高的可用性、更低的成本。在他看来，护城河从来不是算力规模，而是「我们和研究员积累下来的 IP、诀窍和想法」（原文："The moat is sort of like the IP, the trade secrets, the ideas that we and our researchers have built."）——这靠的是服务真实客户、搭建定制服务引擎、不断收集实战反馈积累出来的系统级优势，大厂没法一夜之间复制。
