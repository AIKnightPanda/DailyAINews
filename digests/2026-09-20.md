### Box CEO Aaron Levie：个人 agent 争的不是用户注意力，是 agent 注意力

他说「为 agent 打造产品」正在成为新方向，类似 Muse 这样的产品，核心形态是你把一个任务完整甩给 agent，让它端到端做完——这就要求 agent 能真正操作你的工具或调用自己的工具去完成任务：用你的 MCP 或 CLI、能在你网站上导航、能完成交易。

他的判断很直接：「你现在要争夺的注意力，不再来自用户本身，而是来自 agent。」（原文："The new attention you need to compete for is not from the user itself but instead for the agent."）那些能让 agent 点外卖、处理电商交易、订机票、跟本地经济和你的数据打交道的工具，会成为用得最多的工具——他认为这会是消费互联网自 App Store 以来最大的一次洗牌。

### AI 教程作者 Peter Yang：用一个 markdown 文件 + /tastemaker skill 做个人品味助手，考虑要不要开源

他分享了一个简单的个人工作流：一份 markdown 文件配上一个 /tastemaker skill，专门给看过的电影、剧集、书打分。每周它会自动检索新上映的内容和还没看过的东西，给出他觉得很贴合口味的推荐。

他把这个思路抛给读者：「要不要把这个开源？」（原文："Should I open source this?"）

🔗 https://x.com/petergyang/status/2101503916743749878

### Vercel CEO Guillermo Rauch：这波 AI 热潮最酷的地方，是所有人都在兴奋地做东西

他说排除掉短期的各种争议和噪音，这一点对世界是一件好得没法衡量的事：大家想要创造和发布，而不只是消费。

「这波 AI 浪潮最酷的一点是，每个人都对做东西这件事感到兴奋。」（原文："The coolest thing about the recent wave of AI is that everyone is excited about building."）

🔗 https://x.com/rauchg/status/2101397206595231765

### FPV Ventures 合伙人 Nikunj Kothari：VC 也得亲自写代码，不然看不懂 AI 时代要发生什么

他说自己每天花大约两小时编程、做 side project、折腾新仓库，经常被人问「你不是 VC 吗，干嘛干这个」。他觉得这个时代节奏太快，不亲自动手根本跟不上接下来会发生什么。

他把想投好 AI 这件事拆成三层：一是读懂模型能力，判断下一代模型会在哪些方向变强——他认为读论文本身还有很多 alpha；二是搞清楚 agent 要完成更长链条的任务需要什么工具（基础设施层）；三是理解 harness 能力怎么让模型帮着搭建自主运行的公司（应用层）。

「不像以前的时代，现在事情变化太快了，如果你不这么做，我实在不知道大家要怎么才能搞懂接下来会发生什么。」（原文："Unlike other eras, things are moving SO fast that if you don't do this, I simply don't understand how folks will ever learn what's coming next."）

🔗 https://x.com/nikunj/status/2101340098356990058

### SPC 普通合伙人 Aditya Agarwal：大厂被境外国家渗透，他觉得已经是板上钉钉的事

看着 Gemini（Google）、OpenAI、Anthropic 一轮接一轮宣布更深的 agent 权限接入，他说自己现在百分之百认定，已经有不少大公司被境外国家渗透过，而这些公司自己还不知道。

「看到 Gemini（Google）、OpenAI 和 Anthropic 接连宣布更多 agent 权限接入之后……我百分百认定，已经有不少大公司被某些国家渗透了，而它们自己还不知道。」（原文："After seeing the rush of announcements by Gemini (Google), OpenAi and Anthropic about even more agent intrusions......I take it for 100% granted that a number of of major companies have been penetrated by nation states without them knowing about it."）
