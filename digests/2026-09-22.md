### Box CEO Aaron Levie：个人 agent 一旦能端到端办事，商业交易会大量流向它们

Aaron Levie，Box CEO，判断能代表用户交易的个人 agent 蕴含巨大的变现潜力。他的逻辑是：一旦 agent 能可靠地端到端处理任意复杂的任务，用户会先把日常琐事丢给它，习惯之后再逐渐丢更复杂的任务，最终通过 agent 花掉的钱反而会超过之前自己动手时花的钱——摩擦一旦被 agent 降下来，消费反而会增加。这既给 Muse 这类 agent 提供方带来机会，也给「agent 想对接的那一层」（商业、本地生活、to B 服务）创造了全新机会，他称之为多层皆赢的局面。

在另一条推文里他补充了配套判断：AI agent 使用软件的频率会是人类的 100 倍，就算交互界面逐渐隐入后台、人主要通过 agent 打交道，那些核心基础设施反而会变得更重要——尤其是 agent 能在系统里执行破坏性操作、或者所处的上下文直接决定工作流成败的场景，比如 CRM、ERP 或结构化/非结构化数据平台。他认为谁能同时做好 agent 的安全层和护栏、管理好人和 agent 共用的数据、编排业务逻辑，谁就抓住了眼下的巨大机会，无论是新创业公司还是能够快速转身的老平台（原文："The platforms that can best act as the security layer and guardrails for agents, manage the data for agents and people, and orchestrate the business logic for workflows have a huge opportunity right now."）。

### Vercel CEO Guillermo Rauch：给 Grok 4.7 出了道逆向工程难题，又快又漂亮地解出来了

Guillermo Rauch，Vercel CEO，分享了一次用 Grok 4.7 解决硬核问题的体验：他给了它一个相当困难的题目，需要对一个正在运行的二进制程序做逆向工程，结果模型「漂亮地解决了，而且速度快得惊人」（原文："I just gave Grok 4.7 a pretty hard problem, involving reverse-engineering a running binary. Beautifully solved. And it's so fast!"）。他同期还提到 AI Gateway 现在支持通过 HTTP 使用 Jev（配合他们自家类型安全的 `aisdk` API）。

🔗 https://x.com/rauchg/status/2102089968860721335 · https://x.com/rauchg/status/2102205684544852121

### YC 主席 Garry Tan：Capy 追踪多步工作流、出大 PR 的速度，比 Codex 和 Claude Code 单独跑都快

Garry Tan，YC 主席兼 CEO，说自己也没完全搞懂 capy.ai 是怎么做到的，但它确实能追踪多步骤工作流，出大 PR 的速度比单独用 Codex 或 Claude Code 更快，成了他过去一周最喜欢的「agentic coding 秘密武器」（原文："Not really sure how @capydotai does it, but it really is able to track multi-step workflow and do large PRs faster than Codex or Claude Code on its own. My most favorite new agentic coding secret weapon in my arsenal the last week."）。他还转发了一个例子：在 GBrain 项目上跑一轮范围很大的 bug 修复，任务划分清楚、自动并行、PR 和 CI 流程干净利落。
