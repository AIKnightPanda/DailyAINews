隐私政策

DailyAINews · 最后更新 2026-09-13

DailyAINews 是一个个人自动化项目：每天抓取、整理并发布一份 AI 行业简报和一份 创业灵感摘要，产出就是你现在能看到的这个公开页面。它请求 Gmail 只读权限， 唯一的用途是读取一个固定白名单里的邮件来源，把里面的公开内容 并入当天的摘要。

它请求了什么权限

只有一个 OAuth scope：gmail.readonly。

只读，不能修改、删除任何邮件，也不能代你发信。这个应用没有申请任何写权限。

它读取哪些邮件

只读代码里写死的发件人白名单（目前是 IdeaBrowser 的每日邮件 和 Mobbin 的每周产品简报两家），白名单之外的邮件不会被列出、也不会被读取。 白名单在仓库里公开可见： scripts/idea-sources.js。

读到的内容怎么处理

  • 写入本地/CI 存储之前，会先剪掉邮件页脚、抹掉带订阅者标识的链接 （比如退订链接里嵌着的身份令牌），并把邮件地址替换成占位符。
  • 公开页面上展示的是从邮件里提炼、翻译出的摘要文字，不会展示邮件原文， 也不会展示任何邮箱地址或订阅者标识信息。
  • 不会把邮件内容或账号信息发送给这个项目以外的任何第三方服务、 不用于广告或用户画像，也不会出售或共享给任何人。

谁能访问

这是单人项目，只有仓库所有者本人的 Google 账号会被这个应用访问。 凭证只保存在项目所有者自己的电脑和该仓库私有的 GitHub Actions Secrets 里， 不会出现在仓库的公开代码或页面中。

怎么撤销授权

随时可以在 Google 账号 → 安全性 → 第三方应用授权 里找到 DailyAINews 并移除访问权限，撤销后这个应用会立即无法再读取任何邮件。

有问题可以到 GitHub 仓库 提 issue。
