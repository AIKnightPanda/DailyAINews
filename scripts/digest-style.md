# 简报写作规范

本地 `scripts/daily.js` 和云端 Routine 共用这一份。想调整简报的风格、长度、取舍标准，改这里即可。

## 语言与结构

- **全文用中文**，但保留人名、公司名、产品名、技术术语的英文原文
- 文件**第一行**必须是 frontmatter，格式严格如下（数值取素材开头给出的统计，`headline` 用一句话概括本期最重要的一两件事，40 字以内，不加引号、不加书名号）：

```
---
issue: <期号，如 2026-08-22>
feed_generated_at: <素材里给出的 feed 生成时间，原样照抄>
builders: <建造者数>
tweets: <推文数>
blogs: <博客数>
podcasts: <播客数>
headline: <一句话概括>
---
```

- 正文按 **X / Twitter → 官方博客 → 播客** 的顺序组织，**只写当期有内容的板块**，并按实际保留的板块**连续编号**（例如当期没有博客，就写成 `## 一、X / Twitter` 和 `## 二、播客`）
- 某个板块因无新内容被略过时，在下一个板块标题后用一行 `>` 引用说明，例如 `> 本期 feed 中官方博客无新增内容，故无博客板块。`
- 每个条目用 `### 标题`，标题要具体（写出人名/机构 + 观点要点），不要写成「某某的推文」
- 每个条目正文之后，另起一段用 `🔗 URL · URL` 列出全部来源链接（阅读器会把这行渲染成可点的链接组）

## 署名与引语

- 介绍作者用**全名 + 职务/公司**，例如「Replit CEO Amjad Masad」「Box CEO Aaron Levie」。
  不要只用姓，不要用带 `@` 的 handle。需要标注账号时写成「Aaron Levie（levie on X）」
- 每个条目**至少引一句原文直接引语**（有值得引的话时），用引号，与素材逐字一致
- 不要写「在这期节目里……」「作者讨论了……」「主持人问到……」这类套话。
  直接进正文 —— 写的是这个人的观点本身，不是「某个内容的摘要」

## 事实纪律

- **绝不编造**任何内容、引语或观点。只写素材里真实存在的东西
- **没有原始链接的内容一律不收录。没链接就等于不存在，宁可不写**
- **不要臆测**某位建造者的沉默，也不要猜他可能在做什么。素材里没有的就是没有
- 素材里若标注了「只给了频道页链接，没有具体视频 URL」，照常写这期播客，但在末尾用 `> ⚠️ 数据说明：…` 如实标注这个缺口

## 补充源的引用编号

素材末尾有一节「补充源条目」，是 AINews、Import AI 和各家官方博客当期的条目，
形如 `[E12] 标题`。**这些条目没有给你 URL，你也不要去写 URL。**

- 正文里确实用得上某一条时，直接写编号：`……这一点在 AINews 当天的汇总里也有印证[E12]。`
  构建脚本会把 `[E12]` 换成带标题的真链接
- **不要逐条罗列这些条目** —— 全部条目都会由脚本自动列在简报末尾的「延伸阅读」一节，
  你重复一遍纯属浪费
- 只在编号确实对应你正在讲的内容时才引用。宁可不引，也不要为凑数硬引
- **绝对不要自己编造或拼接 URL。** 你能写出的合法链接只有两种来源：
  推文和博客素材里明确给出的链接，以及 `[E<编号>]` 这种引用标记
- 引用原话时用引号，并确保与素材逐字一致

## 取舍

- 跳过没有实质内容的推文：纯转发、活动吆喝、无正文的纯链接、互动话术、梗图、与 AI/构建无关的社会议题
- 某位建造者当期没有实质内容就**整个跳过**，不要为凑数写「暂无要点」
- 有料的条目展开写（3–6 段），没料的果断略过。宁可短，不要注水

## 各板块要求

- **推文**：首次提到某人时写出**全名 + 职位/公司**，句中引用 X 账号写成 `levie on X` 这种形式，**不要带 @**（带 @ 在某些客户端会变成误导性的链接）
- **博客**：100–300 字，先讲最重要的发布或发现，有具体数字就写出来，尽量带一句原文引语
- **播客**：200–400 字，开头一句加粗的「**核心结论**」，介绍讲者身份和为什么值得听，包含至少一句直接引语，优先写反直觉或具体的洞见而非泛泛道理
  - 素材里的播客内容有两种形态，写法不同：
    - **「通读全文提炼的要点」** —— 覆盖整期，可以放心概括全篇脉络
    - **「采样片段（⚠️ 只覆盖约 N%）」** —— 你只看到了一部分。可以写你看到的，
      但**不要用「整期围绕…」「最后他总结道…」这类暗示你读完了全篇的说法**，
      也不要推测没看到的部分讲了什么
