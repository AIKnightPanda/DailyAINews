# 预处理规范（给 Haiku 子代理）

云端 Routine 第 2 步会起一个 model 为 haiku 的子代理，让它读这份文件并执行下面两个任务。
想调整播客要点的规格、补充源的筛选尺度或翻译口径，**改这里即可**，不用碰 Routine 界面。

为什么交给小模型：播客转录动辄六七万字符，让写简报的主会话读它既贵又会稀释注意力。
这一步只是提取、筛选和翻译，不需要更强的模型。

两个任务彼此独立，其中一个失败不要重试，把另一个做完就交付。

---

## 任务 A：播客要点提炼

仅当第 1 步 JSON 里的 `stats.podcastEpisodes` 不为 0 时执行。

```
node scripts/extract.js <期号> --transcripts
```

**通读全文**，不要只看开头。为每一期播客提炼 **700–1000 字**中文要点，覆盖整期。

这份要点是主会话唯一能看到的播客内容 —— 它写简报时不会再读转录。所以你漏掉的
就是永远丢掉的。要点的目标是**让主会话能写出一篇好稿子**，不是自己写成一篇稿子。

要点里必须有：

- **核心结论** —— 整期最重要的那一两个判断
- **关键数据** —— 数字原样保留，不要四舍五入、不要改写成「大约」
- **值得引用的原话** —— 至少 3 句，**逐字照抄英文原文**并标明是原话。
  主会话要靠这些引语，你转述过一道它就没法用了
- **讲者身份背景** —— 姓名、职务、公司、为什么值得听他讲这个
- **反直觉、反共识、或者具体到只有他这个位置才讲得出来的内容** —— 优先保留这些。
  「要拥抱变化」「人才最重要」这类谁都能说的话不要占篇幅
- **具体案例和做法** —— 他到底怎么做的，而不是他主张什么

不要写文风优美的散文，只要密度高的事实要点。分点或分段都行，怎么密怎么来。

写入 `digests/summaries/<期号>.json`：

```json
{"podcasts": ["第一期的要点…", "第二期的要点…"]}
```

数组顺序必须和转录里的出现顺序一致。

> **写 JSON 的坑**：要点里一定会有英文引号，直接拼进 JSON 字符串会炸。
> 用 `JSON.stringify` 生成，或者确保引号都转义了 —— 写完跑一次
> `node -e "JSON.parse(require('fs').readFileSync('digests/summaries/<期号>.json'))"` 自检。

## 任务 B：补充源条目的筛选与翻译

```
node scripts/extract.js <期号>
```

找到末尾的「补充源条目」一节，每条形如 `[E12] <来源> 标题 —— 背景说明`。
做两件事，结果写入 `digests/extra-zh/<期号>.json`：

```json
{
  "drop": [29, 34, 52],
  "sections": {"AI Twitter Recap": "X / Twitter 汇总", "…": "…"},
  "1": ["英文原标题前 18 个字符", "中文标题", "中文背景说明"],
  "2": ["...", "中文标题"]
}
```

### 筛选

`drop` 数组列出与 AI 无关的条目编号。聚合源里常混进纯生物医药、军事装备、
生活类的条目，剔除掉。判断标准是「一个 AI builder 会不会关心」——
AI 硬件、机器人、AI 政策都算相关；癌症疫苗、阅兵、种菜照片不算。
**宁可少剔也不要误伤，拿不准就留着。**

### 翻译

每个值是数组，**第一个元素是英文原标题的开头 18 个字符（原样照抄）**，
第二个是中文标题，第三个是中文背景说明。按来源区别对待：

- **OpenAI / Google DeepMind / Import AI**：标题和背景都译（三个元素）
- **AINews / The Rundown AI**：**只译标题**（两个元素）——
  这两个源在版面上只显示标题，译背景是白花 token

第一个元素是给脚本做编号对齐校验用的 —— 编号一旦错位，中文标题就会静默地
挂到错误的链接上。校验不过时脚本会整条退回英文。
（脚本比对前会抹平弯引号/直引号这类字形差异，照抄时不用纠结标点形状。）

翻译口径：

- 译成自然流畅的简体中文，**读起来要像中文原生写的，不是翻译腔**
- 技术术语保留英文：AI、LLM、GPU、API、fine-tuning、RAG、token、prompt、
  agent、transformer 这类中文从业者本来就说英文的词
- 专有名词一律保留英文：人名、公司名、产品名、工具名
- 背景说明**按原意翻译，不要自己发挥或补充原文没有的信息**
- **不要输出任何 URL** —— 你也看不到 URL，脚本会按编号自己配回去
- 译不动的条目直接跳过，缺哪条就用英文原文

### 层级标题

`sections` 里放板块 / 子版块 / 主题的译名（素材里形如
`【AI Reddit Recap › /r/LocalLlama › 1. Qwen…】`）。中文版是英文版的提炼，
层级标题也该是中文。subreddit 名这类专名保留原样，查不到译名就用原文。

AINews 的 Twitter 板块用独立段落做分组（如「Agent Harnesses, Persistent Agents,
and Enterprise MCP」），和 Reddit 的子版块同级，同样要译。
